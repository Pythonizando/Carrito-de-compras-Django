# Carrito de Compras Django / Django Shopping Cart

## Español
Proyecto ejemplo de un carrito de compras utilizando Django. Permite agregar productos, gestionar el carrito y realizar compras dentro de un entorno web.

### Tecnologías
- Python
- Django

### Cómo usar
1. Clona el repositorio.
2. Crea un entorno virtual.
3. Instala dependencias.
4. Ejecuta migraciones y el servidor.

---

## English
Example shopping cart project using Django. Lets you add products, handle the shopping cart, and make purchases in a web environment.

### Technologies
- Python
- Django

### How to use
1. Clone the repo.
2. Create a virtual environment.
3. Install dependencies.
4. Run migrations and the server.
